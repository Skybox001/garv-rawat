About

I build retrieval augmented generation systems and deep learning models that hold up outside a notebook, with evaluation as a first class part of the build rather than an afterthought. Most of my work lives where NLP, RAG pipelines and backend engineering meet: retrievers that get tuned, latency that gets measured, and failure modes that get named. I care about systems that are measurable, honest about their limits, and simple enough for someone else to run.

01Projects

PROJECT 01

Production RAG Chatbot

Semantic search kept returning plausible but wrong chunks, so answers drifted. The fix was treating the retriever as a trainable component.

Result: Recall@10 improved from 77.8% to 86.7% using MultipleNegativesRankingLoss on fine-tuned all-MiniLM-L6-v2 embeddings. Built a RAGAS evaluation harness so every retriever and prompt change is scored instead of eyeballed.
